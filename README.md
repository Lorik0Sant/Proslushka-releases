# Прослушка на красные — Arena Breakout: Infinite

Программа слушает звук игры. Когда у полевого торговца дёргаешь закрытый груз, она узнаёт
его звук и показывает, что внутри может быть: красные, золотые, фиолетовые — с шансами.
Размер и цену груза торговец показывает сам: нажми их в окне программы, и шанс красного
станет точным.

**🔑 Ключи доступа и новости — в Telegram-канале [@LorikoSant_Shop](https://t.me/LorikoSant_Shop).**

## Скачать

**[Прослушка — последняя версия (zip)](https://github.com/Lorik0Sant/Proslushka-releases/releases/latest/download/Proslushka.zip)**

1. Распакуй архив целиком (например, на Рабочий стол) и запусти `Прослушка.exe`.
   Windows может показать «Windows защитила ваш компьютер» → «Подробнее» → «Выполнить в
   любом случае»: так она встречает любую программу без платной цифровой подписи.
2. При первом запуске введи ключ доступа `PRSL-XXXXX-XXXXX-XXXXX-XXXXX` — ключи выкладываются
   в Telegram-канале [@LorikoSant_Shop](https://t.me/LorikoSant_Shop).
   Один ключ — один компьютер; на своём компьютере ключ можно вводить снова
   (после переустановки или с новой версией). Если программа пишет «уже активирован на другом
   компьютере» — ключ забрали раньше тебя, возьми другой.
3. Подробная инструкция — «Как пользоваться.txt» внутри архива.

Нужна Windows 11 или Windows 10 версии 2004 и новее.

## Античит

Программа не трогает игру: не открывает её процесс, не читает память, ничего не внедряет
и не нажимает за тебя кнопки. Звук берётся штатным механизмом Windows — тем же, что у OBS
для захвата звука приложения. При этом правила игры формально могут запрещать сторонние
программы, дающие преимущество, — решай сам.
